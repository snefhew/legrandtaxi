1. WhatsApp deep link primary flow

This is what the main "Reserveer" button should point to. It's a plain wa.me URL — no backend, no account, no API key. It just opens WhatsApp with the message pre-typed; the customer still presses Send themselves.

Open WhatsApp naar Michell →

Number format used: Michell's 06 85 63 90 77 becomes 31685639077 for the URL (international format, no leading +, no 00, no leading trunk 0). The message text is built with encodeURIComponent() so line breaks, €, and accented characters survive correctly.

3. Fallback: form-to-email (Web3Forms) needs 1 setup step

    

      For customers without WhatsApp. This is a genuine, static, no-JavaScript-required HTML <form> — it works exactly like this on GitHub Pages with no build step and no server.
      It currently points at a placeholder access key (YOUR_WEB3FORMS_ACCESS_KEY) so it will not actually deliver until a human replaces that key — see the checklist below.
      A honeypot field is included to cut down obvious bot spam.
    

    

      
      
      
      
      
      
      
      
      
      

        

          
          
        

        

          
          
        

      

      

        

          
          
        

        

          
          
        

      

      
      
    

  


  

    
What a human still needs to do

    
    
      
  • WhatsApp button: nothing — it already works with Michell's real number. No account, no signup, no cost.
    • 
      
  • Google Calendar link: nothing — it's a plain URL, works immediately.
    • 
      
  • Fallback form: go to web3forms.com, enter an email address (Michell's), and copy the free access key it emails you. Paste that key into the value="YOUR_WEB3FORMS_ACCESS_KEY" hidden field above (and later in the real site's form). No account password needed beyond the emailed key — takes about 2 minutes. (Formspree is an equally valid alternative if a fuller dashboard/account is preferred instead of a bare access key.)
    • 
      
  • Confirmation email: in the Web3Forms (or Formspree) dashboard, turn on the "auto-response to submitter" option and write a short Dutch confirmation message, so the customer gets an immediate "we hebben je aanvraag ontvangen" email even before Michell replies.
    • 
      
  • Wiring into the real site: once the access key is set, this exact WhatsApp + Google Calendar + fallback-form pattern can be dropped into the live index.html reservation sections (replacing the current href="#" Reserveer buttons) — deliberately not done here per the research-only scope of this task.
